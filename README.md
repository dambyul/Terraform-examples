# Terraform Examples

이 리포지토리는 Terraform을 사용한 Infrastructure as Code (IaC) 구축 예제를 제공합니다. 

## 소개

다양한 클라우드 공급자에 대한 인프라 자동화 스크립트를 관리하고 공유하기 위한 목적으로 작성되었습니다. 현재는 AWS 예제를 포함하고 있으며, 추후 다른 클라우드 환경(Azure, GCP 등)에 대한 예제도 추가될 예정입니다.

## 포함된 예제

### [AWS-sample-1](./AWS-sample-1)

AWS 환경에서 운영 가능한 수준의 인프라를 구축하는 예제입니다. VPC, 서브넷 구조, RDS, EC2(Bastion, Airflow) 구성 등을 포함합니다. 자세한 내용은 해당 폴더의 README를 참조하세요.
